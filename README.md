# BoardGame_Ontology
A Modern Board Game Ontology: Inference and classification for Game Library Managers

This project contains a Bachelor's Degree Final Project at  **Universitat Oberta de Catalunya (UOC)**

## Objectives

- To specify the ontology requirements through an Ontology Requirements Specification Document (ORSD).
- To design and implement an OWL ontology using Protégé.
- To populate the ontology with a sample of 50 modern board games.
- To infer classifications through logical axioms and automated reasoning.
- To validate the ontology using the Pellet plugin and by the competency questions by SPARQL queries.

## Methodology

Iterative and inclemental METHHONTOLOGY and NeOn methodology using BoardGameGeek XML API2 to get the sample for populating the ontology. The publication of extracted data is subject to the terms of use.

## Technologies

- OWL
- RDF
- Protégé
- Pellet reasoner
- SPARQL
- Python
- Cellfie plugin
